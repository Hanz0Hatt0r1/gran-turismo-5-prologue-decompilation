# Import identity catalog

This directory records independently verified PS3 import-library/NID identities used as
evidence in build-specific reverse-engineering notes.

Import names describe the imported platform API symbol. They do not, by themselves,
establish the semantic name of the calling game function.

## Source discipline

Each promoted NID keeps an external source reference and a confidence level. The catalog
is limited to identities independently verified from public PS3 NID documentation or
equivalent technical sources.

The executable and SDK material are never stored here.
