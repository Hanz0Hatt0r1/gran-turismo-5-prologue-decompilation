# Development setup

Keep all local game material outside the repository.

## Recommended layout

```text
workspace/
├─ gran-turismo-5-prologue-decompilation/
└─ local-research/
   ├─ dumps/
   ├─ extracted/
   ├─ tool-projects/
   └─ private-notes/
```

## Typical tools

- disassembler/decompiler;
- hex/binary inspection tools;
- Python;
- debugger or emulator-based observation environment where lawful;
- Git.

## Clone

```bash
git clone https://github.com/Hanz0Hatt0r1/gran-turismo-5-prologue-decompilation.git
cd gran-turismo-5-prologue-decompilation
```

## First contribution

1. Select an issue.
2. Create a branch.
3. Add or update an analysis note under `analysis/`.
4. Include reproducible evidence and a confidence level.
5. Open a pull request linking the issue.
